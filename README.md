# 🔢 Glass Calculator — Advanced Web Calculator

A modern glassmorphism calculator built entirely with HTML, CSS and JavaScript. No libraries, no frameworks — pure vanilla code.

## 🌐 Live Demo
http://www.webdev.cs.uregina.ca/~dtw348/Projects/Project1-FlappyBird/Project3/calculator.html

## 💡 What It Does
A feature-rich calculator with a stunning glassmorphism design, scientific functions, calculation history, and a live graph plotter.

## 🛠️ How I Built It
Built entirely from scratch using vanilla HTML, CSS and JavaScript. The graph plotter uses the HTML5 Canvas API to draw mathematical functions. The glassmorphism UI uses CSS backdrop-filter and layered gradients with animated background orbs.

## ✨ Features
- Basic and Scientific modes
- Scientific functions — sin, cos, tan, log, ln, square root, x², x³, xʸ, 1/x, absolute value, π, e
- Live preview — shows result as you type
- Calculation history — saved in localStorage, persists between visits
- Click any history item to reuse the result
- Graph plotter — type any function like x^2 or sin(x) and plot it live
- Full keyboard support — type numbers and operators directly
- Glassmorphism design with animated gradient background
- Fully responsive — desktop shows 3 panel layout, mobile stacks perfectly

## 🗄️ Tech Stack
- HTML5 Canvas for graph plotting
- CSS3 with backdrop-filter glassmorphism
- Vanilla JavaScript — zero dependencies
